# 📚 Library Management System

A modern, role-based Library Management System built to streamline library operations with a secure and intuitive user experience. The platform enables **Users**, **Librarians**, and **Moderators** to efficiently manage books, borrowing, returns, reservations, and library activities through dedicated dashboards.

The system also includes an **AI Chat Assistant** to help users quickly navigate the platform, answer library-related questions, and provide instant assistance.

# 🔐 User Roles

| Role | Description |
|------|-------------|
| User | Browse books, borrow books, reserve books, renew books, manage profile, and interact with the AI Assistant. |
| Librarian | Handle daily library operations including books, borrowing, returns, reservations, and fine collection. |
| Moderator | Manage users, librarians, system settings, analytics, reports, and monitor the entire platform. |
